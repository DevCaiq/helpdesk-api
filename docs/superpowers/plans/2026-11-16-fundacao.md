# Fundação do Help Desk — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Iniciar o projeto com configurações por ambiente, usuário customizado antes da primeira migration, verificações de saúde, testes SQLite e configuração PostgreSQL/Docker.

**Architecture:** Django modular com settings separados. A fundação define autenticação e integridade do usuário, sem antecipar endpoints de atendimento. Serviços e SLA serão entregues em etapas posteriores do roadmap aprovado.

**Tech Stack:** Python 3.12, Django 5.2 LTS, DRF, uv, pytest-django, SQLite no desenvolvimento/testes locais e PostgreSQL em produção.

**Spec:** `docs/desenho-tecnico.md` e `docs/decisoes-iniciais.md`.

## Global Constraints

- SQLite no desenvolvimento e testes padrão; PostgreSQL somente em produção, com verificação de compatibilidade no CI.
- Custom user antes da primeira migration; login por e-mail.
- Primeira resposta 2h e fechamento definitivo após 48h conforme desenho, a implementar no módulo de chamados.
- Sem publicação externa nesta etapa; trabalho em D:\gsti, atualmente sem repositório Git.
- Não instalar ferramentas globalmente; ferramentas auxiliares e caches ficam no workspace.

## Review Focus

- Cadastro de superusuário não pode criar conta sem senha ou sem privilégios administrativos.
- E-mail com capitalização diferente não pode criar contas duplicadas.
- Nível é obrigatório somente para Analista, com integridade também no banco.
- Readiness deve retornar 503 sem expor erro de banco; health permanece independente do banco.
- Produção deve rejeitar SQLite, DEBUG e ausência de segredo.
